# F-05 completed: explicit ranges and restored defaults

Product revision `7c3072c821cc` keeps automatic worker selection at file granularity. Explicit `-jN` with N > 1 enables ranges for one requested large file per directory. Kernel reflinks and same-device native copy ranges on btrfs/XFS, and macOS F_NOCACHE at 1 GiB, remain automatic. There is no new wire option.

The frozen Release reference is the pre-F-05 product `f3d110d229e3` at four workers; the candidate is measured with automatic worker selection and a one-worker control. Worker budgets differ deliberately in this default-policy comparison. Earlier explicit-four-worker comparisons retain both benefits and regressions; [revision 98eeb171c94d results](20261010-f05-98eeb17-summary.md) must remain visible when choosing an explicit range budget.

Each filesystem completes 112 timed samples and 28 untimed verified warmups, with four rotated tool positions. Single-file cases copy 256 MiB; two-file cases copy 512 MiB. Every result passes independent rsync checksum/metadata verification. All 21 candidate/reference median ratios exceed 0.85; this local comparison is separate from the production CI gate, which uses matched automatic worker settings and 24 samples.

Linux measurements use an ARM64 Docker VM; btrfs is a disposable 2 GiB loop-backed volume, with delayed frees settled before each timed copy. macOS is a busy developer host, so these results do not settle F-07 filesystem defaults. CPU includes waited-for children; peer CPU is supplemental and is not added twice. RSS is a process high-water mark.

Five instrumented range tests pass per platform, covering default serialization, explicit overlapping I/O within the worker budget, one-worker control, compressed transfer, frozen-peer compatibility and eight producers. The final glibc and static-musl products each pass three actual FICLONE, COW independence, mode preservation and opt-out tests on both btrfs and XFS (12 tests total). [The native filesystem log](20261010-f05-7c3072c-native-fs.log) retains these checks and the full btrfs comparison. The prior range implementation also passed all 231 macOS and 227 Linux differential cases, seven Linux kernel fault/policy tests, adaptive compression and resume tests; the final selection change has its focused instrumented coverage.

The expanded hosted gate is running for product `0ece0c58b773`, whose production source matches `7c3072c821cc`. It protects all 18 scenarios with the unchanged 85% floor. Its result remains a product acceptance check; this story completion does not imply the pending run has passed.
