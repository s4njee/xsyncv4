The revised policy restores automatic two-file copies on overlay and retains btrfs reflinks. Single-file byte copies and plain pipe transfers still regress in several cases. The single compressed pipe is 1.60x faster on overlay and 1.07x faster on this busy Mac. These gains do not establish a universal improvement; F-05 remains partial while the uncompressed single-file policy is investigated. macOS starts at load 36, so these timings do not establish quiet-host filesystem defaults.

Final glibc and static-musl products each pass three actual FICLONE/COW/mode/opt-out tests on both btrfs and XFS (12 total). The supporting [native filesystem log](20261010-f05-98eeb17-native-fs.log) retains both filesystem creation metadata and the complete btrfs comparison. All 231 macOS itemized differential cases and 227 Linux data/metadata cases pass. Four range tests pass on each platform with a frozen prior peer, and seven resume tests per platform pass (the optional real SSH rig test is skipped). Adaptive compression passes its platform tests; the optional pre-policy peer test was not repeated in this final batch.
