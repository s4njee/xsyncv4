# Main lab results

The home lab's results (dashboard.mk7s.dev), published once a day by benchmarks/lab/publish_main.py: every run's plan, samples, blocks and analysis (results/), the planner's windows, the engineer's cases, preflight records, the daily collections of lab2's gaps (results/lab2/), and the experiment specs and trees (experiments/). home-ratios.json gives, for each cell lab2 measures, the home lab's measurements of the closest home tree and scenario. Host names, addresses and home directories are scrubbed; files over 50 MB are gzipped.
