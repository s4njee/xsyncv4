# lab2 results

The VPS lab's results (lab2.mk7s.dev), published once an hour by benchmarks/lab/publish_results.py:
manifest.json (the builds raced, the machines and link), engineer.json (port steps and cases), each run's plan,
samples, blocks and analysis (runs/), the scoreboard of rsync, xs-c++ and xs-rs (contest.json), the daily Analysis report,
and the engineer's case records and DevLog. Host names, addresses and home directories are scrubbed, and no logs or
agent transcripts are included.
