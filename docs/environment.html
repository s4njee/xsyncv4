XSYNC USER MANUALSECTION 5

xs-config(5) ​

Environment & defaults

Set personal defaults and understand which layer wins.

FILES ​

The default config is $XDG_CONFIG_HOME/xsync/config, or ~/.config/xsync/config when XDG_CONFIG_HOME is unset. A missing default file is ignored. An explicitly selected missing file is an error.

A defaults file
sh
# ~/.config/xsync/config
--progress
--jobs=4
--exclude 'scratch files'

Blank lines and full-line comments are allowed. Quoting splits words; variables, commands, and ~ are never expanded. Defaults contain flags and values, with transfer paths on the command line. Control actions such as install/server/help/version are not defaults.

PRECEDENCE ​

For scalar options and on/off flags: command-line flags → environment → config. Within a layer, the last value wins. Repeatable options accumulate from config, then environment, then command-line flags; --filter=! clears earlier filter rules.

An explicit command-line override
sh
export XSYNC_OPTS='--jobs=8 --no-progress'
xs --progress src/ dst/

ENVIRONMENT ​

VariableMeaning
XSYNC_CONFIGAlternate config path; an empty value disables config
XSYNC_OPTSShell-quoted default option string
XSYNC_PROGRESS0 disables; 1 enables; auto retains defaults; explicit flags win
XSYNC_FALLBACK0 disables fallback; --fallback overrides it
XSYNC_RSHRemote shell, ahead of RSYNC_RSH and defaults
RSYNC_RSHRemote shell when higher-priority settings are absent
XSYNC_REMOTE_PATHExtra remote helper lookup path
XSYNC_RELEASE_DIRRelease artifacts for explicit remote install
NO_COLORDisable color escapes in progress

REMOTE SHELL PRECEDENCE ​

--rsh/-e, then XSYNC_RSH, then RSYNC_RSH, then a shell in XSYNC_OPTS, then config, then ssh. Empty shell values are rejected.

Set the remote shell through the environment
sh
export XSYNC_RSH='ssh -p 2222'
xs -azP src/ user@host:/backup/

CONTROL DEFAULTS EXPLICITLY ​

Disable personal defaults and require native execution
sh
XSYNC_CONFIG='' XSYNC_OPTS='' xs --no-fallback --no-progress -a src/ dst/

Check inherited XSYNC_* and RSYNC_RSH variables when making a fully controlled script. Explicit flags override progress and fallback defaults; supply -e if the remote shell must also be fixed.
